## Project Description
**My Cafe** is a responsive, accessible, 10-page static website evolved directly from the original Lab 11 single-page My Cafe foundation. It faithfully preserves the original beige background (`#F5F5DC`), brown headings and tables (`#A52A2A`), dark green accents (`#006400`), Arial typography, interactive welcome alert, and all six original menu items and prices (`Espresso Rs. 250`, `Cappuccino Rs. 350`, `Latte Rs. 300`, `Milk Tea Rs. 150`, `Green Tea Rs. 180`, `Black Tea Rs. 120`), while expanding into a cohesive multi-page coffeehouse experience built strictly with HTML5, CSS3 (`style.css`), and vanilla JavaScript (`script.js`).

## Repository Structure & Pages
All ten HTML files, the shared stylesheet, and the shared script reside in the repository root for seamless GitHub Pages deployment:

1. [`index.html`](index.html) — Homepage with hero banner, brand story, featured original menu cards, illustrative seasonal combos, cafe highlights, gallery preview, illustrative testimonials, and calls to action.
2. [`menu.html`](menu.html) — Comprehensive food and beverage menu divided into 5 categorized tables (Coffee, Tea, Cold Drinks, Specialty Beverages, Bakery & Desserts) with live category filtering and keyword search.
3. [`gallery.html`](gallery.html) — Interactive 9-photo showcase across coffee, tea, bakery, and interior categories with category filters and keyboard-accessible full-screen lightbox.
4. [`about.html`](about.html) — Brand evolution from Lab 11 to Lab 12, mission, vision, core values, operational quality standards table, and illustrative team roles.
5. [`coffee.html`](coffee.html) — Educational coffee guide comparing Arabica vs. Robusta beans, a 4-tier roast level comparison table, and brewing techniques.
6. [`experience.html`](experience.html) — Detailed overview of interior ambience, seating zones (quiet study zone, social booths, espresso bar), and guest etiquette.
7. [`events.html`](events.html) — Clearly labeled sample workshops, latte art classes, tea tasting flights, and community reading circles.
8. [`reservation.html`](reservation.html) — Table reservation enquiry form with full JavaScript input validation and demonstration confirmation output.
9. [`contact.html`](contact.html) — Illustrative operating hours table, placeholder academic contact details, and validated demonstration contact form.
10. [`faq.html`](faq.html) — Categorized Frequently Asked Questions with live keyword search and accessible ARIA accordion toggles.
11. [`style.css`](style.css) — Shared responsive design system preserving Lab 11 colors and Arial typography with reduced-motion support.
12. [`script.js`](script.js) — Shared vanilla JavaScript powering mobile navigation, Lab 11 `window.alert()`, menu filtering/search, gallery lightbox, FAQ accordion, and form validation.

## How to Run Locally or Deploy on GitHub Pages
1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser (no build step or server required).
3. To deploy on **GitHub Pages**, push all files to the `main` branch, open **Settings > Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
